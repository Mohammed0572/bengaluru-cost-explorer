## Reporting a Vulnerability

We take the security of this project seriously. If you discover a security vulnerability, please report it responsibly.

**Please do not open a public GitHub issue for security vulnerabilities.**

### How to Report

Use GitHub's private vulnerability reporting feature:

1. Go to the [Security tab](https://github.com/Mohammed0572/bengaluru-cost-explorer/security) of this repository
2. Click **"Report a vulnerability"**
3. Provide a detailed description of the issue, including steps to reproduce it if possible

Alternatively, you may reach out directly to one of the maintainers:

- [Pranav](https://github.com/toxicbishop)
- [Syed](https://github.com/Mohammed0572)
- [Rohith R.](https://github.com/Rohithgaloth)
- [Supreeth](https://github.com/supr1795)

### What to Expect

- We will acknowledge receipt of your report within **48 hours**
- We will investigate and provide status updates as the issue is triaged
- Once resolved, we will coordinate with you on disclosure timing before any public write-up

### Scope

This is a student/academic project. While we will make a good-faith effort to address reported vulnerabilities, please understand response times may vary based on maintainer availability.

Thank you for helping keep this project and its users safe.
